# Materials Funnel

1. **Evidence summary** (public-facing, E2-internal labeled)
2. **Reproduction protocol** (shared with serious technical prospects)
3. **Review packet** (external review candidates)
4. **External reproduction** (once a third party actually reproduces results)
5. **Enterprise R&D pilot**

Claims discipline: never "E3" or "validated externally" before stage 4 actually happens — see
`07_MATERIALS/MATERIALS_CLAIMS_BOUNDARY.md`.
