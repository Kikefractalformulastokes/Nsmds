# Public / Private Boundary

What never leaves internal docs into public copy, ads, or this-command-center-turned-public:

- CEOS company-state numbers with internal context (even though the numbers themselves — 0
  customers, 0 revenue — aren't secret, the surrounding internal deliberation isn't public-ready)
- Unpublished pricing negotiation notes
- NS-MDS internal method/parameter details not yet gated for release (per
  `research/paper-01-dual-observable/PUBLICATION_GATE.md`)
- This command center's internal task board (`CEOS_AGENT_SYNC_BOARD.md`) and any file marked
  INTERNAL/CONFIDENTIAL per `16_SECURITY_GROWTH/01_SECURITY/DATA_CLASSIFICATION_POLICY.md`
- Draft ad copy, draft case studies before consent/QA clears them

Public-safe: published paper drafts (status-labeled), approved marketing claims, published demo
pages carrying the correct DEMO/PUBLIC-SOURCE label.
