# Follow-up System

Cadence template (not yet in force — no leads exist):

| Status | Follow-up timing |
|---|---|
| CONTACTED, no open | +3 days |
| OPENED, no reply | +5 days |
| REPLIED | Same/next business day |
| QUALIFIED, no call booked | +2 days |
| PROPOSAL sent, no response | +3 days, then +7 days |
| FOLLOW_UP_LATER | Per lead's stated timing, tracked in `LEAD_PIPELINE.csv` |

No automation exists — this is a manual-process spec pending a real CRM tool decision.
