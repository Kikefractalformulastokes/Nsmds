# Lead Scoring Rules (draft framework)

Score components (weights are a starting hypothesis, to be tuned once real lead data exists):

- Fit (role/company/sector matches ICP): 0-40
- Intent (source + action taken, e.g. pricing page view > checklist download): 0-30
- Engagement (replied, booked a call): 0-30

Qualification threshold: not set — no real leads exist yet to calibrate against. Do not treat any
number here as final; revisit after the first 20-30 real leads.
