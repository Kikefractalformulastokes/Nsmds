# Analytics Master Plan

**Status: nothing installed anywhere.** No analytics tool is connected to this session, and per
the standing rule, no tracking is installed on any live property without Enrique's explicit
approval.

## Sequence

1. Choose a privacy-safe analytics tool (`PRIVACY_SAFE_ANALYTICS_PLAN.md`) — decision owned by
   Enrique.
2. Define events per property (`EVENT_TRACKING_MAP.md`).
3. Define the funnel each event feeds (`CONVERSION_FUNNEL_MAP.md`).
4. Define UTM conventions so paid/organic/social are attributable consistently
   (`UTM_POLICY.md`).
5. Only after 1-4 are approved does the Chrome agent install anything
   (`TRACKING_READY_FOR_CHROME_SETUP.md` is the handoff doc).
6. Build the dashboard (`DASHBOARD_SPEC.md`) once real events are flowing — not before, to avoid
   a dashboard full of mocked data.
