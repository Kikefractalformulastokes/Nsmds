## Sequencing

1. Technical SEO foundation first (`SEO_TECHNICAL_AUDIT.md`, `SITEMAP_ROBOTS_PLAN.md`,
   `SCHEMA_MARKUP_PLAN.md`) — cannot ship content SEO on a broken technical base.
2. Keyword/intent mapping (`KEYWORD_MAP.md`) → content clusters (`CONTENT_CLUSTER_MAP.md`).
3. Internal linking (`INTERNAL_LINKING_PLAN.md`) once 2+ pages per cluster exist.
4. Programmatic SEO (`PROGRAMMATIC_SEO_PLAN.md`) only after the manual cluster proves intent
   match — do not scale a template before validating one page converts.
5. Compressed 90-day plan (`SEO_90_DAY_PLAN_COMPRESSED.md`) sequences all of the above.
