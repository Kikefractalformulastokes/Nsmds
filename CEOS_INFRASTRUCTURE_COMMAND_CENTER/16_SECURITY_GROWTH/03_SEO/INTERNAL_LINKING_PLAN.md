# Internal Linking Plan

Rules (apply once each site is buildable):

1. Every pillar page (see `CONTENT_CLUSTER_MAP.md`) links out to all of its cluster's supporting
   content, and every supporting piece links back to its pillar.
2. Cross-vertical links only where genuinely relevant (e.g. Aerospace page links to CEP/Evidence
   Package explainer, not to RiesgoDeObra).
3. Every page has at least one contextual link to a conversion page (Contact, pricing, demo
   request) — no orphaned content pages.
4. Nav + footer carry the top-level structure (`/technology`, `/cep`, `/materials`, `/aerospace`,
   `/research`, `/demos`, `/contact`) consistently site-wide.
5. No link to a page that doesn't exist yet — this plan tracks target structure, not built pages.

**Status:** no pages exist yet in an accessible repo, so no links have been implemented. This is
a ready-to-apply ruleset for whenever CoreSyn web is in scope.
