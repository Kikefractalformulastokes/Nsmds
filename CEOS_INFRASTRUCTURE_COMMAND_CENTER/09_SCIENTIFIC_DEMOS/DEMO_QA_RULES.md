# Demo QA Rules

1. No demo publishes without a primary source or the `DEMO / PUBLIC-SOURCE RECONSTRUCTION` label.
2. No demo implies it is validated/certified/endorsed by any third party.
3. No demo omits limitations.
4. Every numeric/visual claim in a demo traces to a cited source or is explicitly marked
   illustrative.
5. Demos supporting Aerospace/Materials positioning still follow `CLAIMS_QA_RULES.md` — a demo
   isn't exempt from claims discipline just because it's "just a demo."
