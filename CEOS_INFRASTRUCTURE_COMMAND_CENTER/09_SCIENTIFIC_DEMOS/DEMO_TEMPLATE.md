# Demo Template

Every demo page/document must include:

```
## Source register
(primary sources this demo reconstructs, with links/citations)

## Claim map
(what this demo claims vs. what it doesn't)

## Evidence matrix
(what's verifiable vs. illustrative)

## Audit summary
(what CoreSyn would audit if this were a real client engagement)

## What CoreSyn would audit
(specific, concrete — not generic)

## Limitations
(explicit, not buried)

## Sources
(full citation list)

## Label
DEMO / PUBLIC-SOURCE RECONSTRUCTION — required, not optional, unless the demo is genuinely
CoreSyn's own primary research (in which case it uses the same status-labeling discipline as
`research/paper-01-dual-observable/` in `nsmds`).
```
